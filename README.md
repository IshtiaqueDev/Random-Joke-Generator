# Random Joke Generator

A simple and interactive **Random Joke Generator** built using **HTML, CSS, and JavaScript**.  
This project fetches random jokes from an API and displays them dynamically whenever the user generates a new joke.

## About The Project

The Random Joke Generator was created to practice and understand how APIs work with JavaScript. Through this project, I explored making asynchronous requests, handling API responses, and managing promises effectively.

This project helped me understand:

- Fetching data from APIs
- Asynchronous JavaScript
- `async/await` syntax
- Promise handling using `.then()` and `.catch()`
- Error handling in API requests
- Dynamic DOM manipulation

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- API Integration

## Features

- Generate random jokes with a single click
- Fetch fresh jokes from an API
- Simple and clean user interface
- Handles asynchronous API requests
- Basic error handling

## Learning Outcomes

While building this project, I improved my understanding of JavaScript fundamentals and gained practical experience working with APIs, promises, and asynchronous programming.
